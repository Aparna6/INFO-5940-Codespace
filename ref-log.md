# 📘 Reference Log

### 🧩 Learning from implementing a multi-agent workflow
The primary learning outcome from implementing a multi-agent workflow is how it improves the quality of the results as well as the performance of the agent when the goal for each agent is more focused. The planner agent is able to anaylyze the user input and generate a well-defined and detailed plan as per the defined criteria without having to focus on validation or feasibility as per real-world facts. The reviewer is then able to consume this well-structured plan to fact check and provide real-time validated suggestions and sources to define a final plan which is feasible, affordable and accurate. Pairing different agents with focused goals provides us with better performance from simple architectures. 

## 📚 Challenges faced and how you addressed them
The main challenge was refining the prompt to give the best output while maintaining a balance which does not restrict the agent too much and leaves room for creativity while satisfying the basic criteria of our final goal. I overcame it by testing various prompts that I could think of to test the agent and its answers.
